# Book Reload Guard and New-Message Positioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop book mode from reloading the native reader when the generated HTML did not change, and make the reader land on the new message after sending a message and after the reply arrives — never on the cover.

**Architecture:** `kt_book_session.lua:do_refresh` rebuilds the HTML and always calls `ui:reloadDocument(...)`, so a provider or preset switch tears the reader down and re-renders for nothing. The new guard compares the freshly built HTML with the bytes already on disk and returns early when they are identical. For positioning, the refresh kinds `"user"` and `"done"` now carry the anchor of the new message (`#mN`, the section id `kt_book.lua` already emits), and `finish_reload` resolves the position as anchor → tail → previous xpointer → keep the current position, with no fallback to page 1.

**Tech Stack:** Lua 5.1/LuaJIT, KOReader native reader (crengine) with `reloadDocument`, `GotoPage`, `GotoXPointer`, `isXPointerInDocument`; existing book smoke harness (`tools/book_smoke.lua`).

**Spec:** `docs/superpowers/specs/2026-11-22-performance-scroll-book-fixes-design.md` (sections "Book reload and positioning", "Approaches considered" → "Book reload: compare the generated HTML" and "Book positioning: anchor first", "Decisions", "Review Focus")

## Global Constraints

- Plain Lua 5.1/LuaJIT; no new dependencies.
- `local _` remains forbidden as a variable name (it shadows gettext).
- The book HTML is generated by `kt_book.lua:Book.build(data)` and written by `Book.save` (temp file + `os.rename`); the write convention must not change.
- The reader integration stays on the native KOReader reader (crengine): no canvas fallback for book mode.
- `#mN` section ids are 1-based message indexes (`kt_book.lua:473`); the anchor format must not change.
- Reveal state (`revealed_spoilers` / `revealed_details`) stays session-only and is cleared on content mutations (`kt_book_session.lua:522`).
- Verification gate for every task: `luajit -bl <file> > /dev/null`, `python3 tools/check_i18n.py`, the book smoke harness, and the UI smoke harness, all run from `/usr/lib/koreader`.
- Do not commit or push without explicit user confirmation.

## Review Focus

- A provider or preset switch in book mode: the reader must not reload — the page number, the reading position, and the read history must survive.
- A reveal toggle (spoiler/details): the HTML *does* change, so the reload must still happen and the position must stay on the toggled message.
- A book where crengine refuses the `#mN` anchor: the reader must keep a sane position — never page 1, never a blank view.
- A chat whose messages were deleted so that the anchor index no longer exists: the reader must fall back to the tail or the previous xpointer, not to the cover.
- An empty chat (no messages): the book must still show its cover (page 1) — that is the one legitimate page-1 jump.
- A generation that ends with an API error (no assistant message appended): the anchor must point at the last existing message and the reader must not jump to a non-existent section.

- [ ] **Step 3: Implement the position chain**

In `kt_book_session.lua`, add the local helper above `finish_reload`:

```lua
-- Where should the freshly reloaded reader land?
--   cover   the book has no messages (the only page-1 jump)
--   anchor  the refresh named a message section (#mN)
--   tail    follow the end of the book
--   old_xp  the exact xpointer the reader had before the reload
--   keep    nothing valid: leave the reader where it is (never the cover)
local function choose_position(pos, has_messages)
    pos = pos or {}
    if not has_messages then return "cover" end
    if pos.anchor and pos.anchor ~= "" then return "anchor" end
    if pos.tail then return "tail" end
    if pos.old_xp and pos.old_xp ~= "" then return "old_xp" end
    return "keep"
end
```

Then rewrite the navigation block of `finish_reload` (`kt_book_session.lua:229-247`) to use it:

```lua
    local choice = choose_position(pos, #(data.messages or {}) > 0)
    if choice == "cover" then
        navigate("GotoPage", 1)
    elseif choice == "anchor" then
        local ok, in_doc = pcall(function() return doc:isXPointerInDocument(pos.anchor) end)
        if ok and in_doc then
            navigate("GotoXPointer", pos.anchor)
        else
            -- The anchor is gone (the message was deleted): fall back to the
            -- tail, then to the previous position - never to the cover.
            if follow_tail then
                navigate("GotoPage", page_count(ui))
            elseif pos.old_xp and pos.old_xp ~= "" then
                local ok2, in_doc2 = pcall(function() return doc:isXPointerInDocument(pos.old_xp) end)
                if ok2 and in_doc2 then
                    navigate("GotoXPointer", pos.old_xp)
                end
            end
        end
    elseif choice == "tail" then
        navigate("GotoPage", page_count(ui))
    elseif choice == "old_xp" then
        local ok, in_doc = pcall(function() return doc:isXPointerInDocument(pos.old_xp) end)
        if ok and in_doc then
            navigate("GotoXPointer", pos.old_xp)
        end
    end
    -- choice == "keep": the reader keeps the position it restored.
```

Remove the old `if not done then navigate("GotoPage", 1) end` fallback (line 245-247).
